# Test, break, fix

**Project, session 4 of 5.** Same routine as week 12, now with **your own** project.

## Set a goal

Write today's goal and your confidence (1–4).

## 1. Build (20 minutes)

Keep building. Focus on what your program **must** do, before anything extra.

## 2. Peer testing (10 minutes)

Swap computers with a partner. They:

1. run **your** test plan,
2. add **three attacks** of their own,
3. record every failure: the input, what should happen, what happened.

Good attacks: empty input, letters instead of numbers, very big numbers, an empty list, the same thing twice.

## 3. Fix (8 minutes)

Fix the **most important** failure first. Update your test table:

| Input | Expected | Actual | Fixed? |
|---|---|---|---|
| | | | |

## Before you leave

Write in your log: what broke, and what did I learn from it?
