# Build the smallest version that works

**Project, session 3 of 5.** Today you start coding in **My project**.

## Set a goal

Write a goal for today: *"By the end of the session I will have ___ working."* Rate your confidence (1–4).

## Start small

Don't try to build everything at once. Build the **smallest version that works**, then test it, then add the next piece.

1. Write one function. Test it.
2. Use it in the main program. Test again.
3. Add the next piece.

**Tip:** while you build, you can test a function on its own with a quick `print(my_function(...))`. Delete the line when it works.

**Need a refresher?** The toolbox exercises in this unit practise useful pieces: a safe number input, searching a list, and counting.

## Conferences

Your teachers will talk with each of you for a few minutes. Be ready to answer: **"Show me the test that proves this part works."**

## Before you leave

Your code saves automatically in **My project**. Write in your log: was your goal met? What is your evidence?
